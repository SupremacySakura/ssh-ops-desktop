# Triage labels

`triage` 技能使用的五个规范标签，标签字符串与角色同名：

| 标签 | 角色 | 含义 |
|---|---|---|
| `needs-triage` | needs-triage | 新议题，等待分诊 |
| `needs-info` | needs-info | 信息不足，需要补充 |
| `ready-for-agent` | ready-for-agent | 已具备上下文，可交给 AI 代理处理 |
| `ready-for-human` | ready-for-human | 需要人类判断/手动处理 |
| `wontfix` | wontfix | 不打算处理 |

标签字符串必须与上表完全一致；如需改名，请同步更新本文件。
