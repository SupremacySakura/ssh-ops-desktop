## 产品定位

**Harbor**（前 OpsPilot）是一款面向个人开发者的本地优先纯 SSH 桌面运维台，运行在 macOS 与 Windows 上。以服务器为唯一工作上下文，在同一工作区内提供终端、文件、监控与 Docker 四个视图。它不是团队协作工具，也不是站点配置或部署工具。

## UI 视觉方向

**Calibrated Panel** — Braun / Dieter Rams 工业设计：暖灰表面、炭黑文字、单一信号橙、镌刻式标签、等宽数字、1px 发丝线。签名动作是“校准刻度”（CPU/内存/磁盘标尺）、完整的服务器铭牌行、工作区左缘常驻书脊。

权威文件：

- `apps/desktop/DESIGN.md`：视觉系统唯一权威。
- `apps/desktop/PRODUCT.md`：产品事实与使用场景。
- `design/harbor-calibrated-panel.html`：1440×900 首屏参考稿。

## 实际落地与计划的差异

以下为重构完成后的真实状态，覆盖本文早期草案中的过期描述：

- **持久化**：SQLite 只保存 `groups`、`servers` 与内部 `known_host_keys`，不保存 `credentials_meta` 或 `command_history`；命令历史只存在浏览器 IndexedDB，监控采样只在内存。
- **测试**：活动 E2E 只有 Playwright 渲染进程层（Vite fixture + Chromium + fake `CoreClient`）；native 测试驱动已删除，且不得恢复。跨边界测试在 `tests/integration`，Rust 侧由 `cargo test --workspace` 覆盖。
- **视觉**：v1 只有一套浅色 Calibrated Panel，不存在“深色默认”或主题系统。
- **范围**：旧自动化子系统、站点配置与隧道均不在 v1，且已从活动代码与文档移除；历史只保留在 `docs/adr/0001-remove-ai-and-task-engine.md` 与 `GLOSSARY.md` 的“已删除术语”。
- **未接线能力**：OpenSSH 证书、SSH agent、端口转发、ProxyJump/ProxyCommand、OpenSSH fallback 均未接入 UI 或命令层，不能按“已支持”宣传。

## 范围外（Out of Scope）

- 旧自动化子系统任何形式的保留（见 ADR 0001）
- 站点配置管理、项目部署、任务中心、审计日志
- 多服务器并行 / 分屏 / 批量操作
- SSH 隧道管理、端口转发 UI
- sz/rz 文件传输协议
- Docker Compose 管理
- 历史监控数据持久化（只看最近 5 分钟实时）
- 主题系统与国际化（v1 只有中文与浅色 Calibrated Panel）
- 自动更新机制
